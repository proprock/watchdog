## Compression benchmark

`python scripts/measure_zstd.py --root <session-directory>` measured 129 local Claude transcript files totaling 99,095,518 bytes on Windows with Python 3.14.3 and zstd 1.5.7. Each file was split into fixed-size byte blocks and each block passed a byte-exact round trip. The stored percentage is compressed bytes divided by raw bytes. Throughput uses raw bytes and excludes source reads and byte comparisons. Medians include only full blocks, with nine samples at 4 MiB and one at 16 MiB.

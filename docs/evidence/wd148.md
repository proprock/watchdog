Applied the decisions of the 2026-10 audit table (4.5) as target policy. The user chose
to state the rules for the not-yet-implemented rule and judge tasks (WD-142 to WD-147) in
full, and to change `config.example.toml` only where a key already exists.

## Changes

- `TENETS.md`: replaced the observation-only hook invariant with the control invariant
  (approved rule, decision channel, confirmed capability, fail-open, kill switches, no
  `continue: false`); added the action, code-approval, and budget rules; replaced the
  no-automatic-LLM invariant with the daemon-judge rule while keeping tests and CI model-free;
  stated the single extension point (`evaluate(ctx) -> Decision`, approved by hash); allowed
  local uncommitted files in any language; one line per task in `DONE.md` with details in
  `docs/evidence/<wd-id>.md`; removed the impact-guided pytest section (local pytest is
  `uv run pytest`, or affected modules by name); moved host-specific limits to `LIVE.md`.
- `AGENTS.md`: removed the model-routing names (moved to `LIVE.md`), kept the provider-neutral
  delegation and output-filtering rules, and pointed the test rules at `TENETS.md`.
- `README.md`, `ROADMAP.md`, `docs/architecture.md`, `docs/hooks.md`: Claude-first scope, the
  per-action precision ladder in place of the single 90% gate, the daemon judge decision,
  an M-Control section, the observation-hook timeout carve-out for control subscriptions,
  and the decisions on `insights_redact` and optional `assistant_text`. README "Status" was
  not extended for unimplemented features.
- `config.example.toml`: `log_detail = true` recommended for a local installation (default
  unchanged). The keys for `assistant_text` and `insights_redact` are attached to WD-145.
- Not changed, by the audit's "keep" rows: worktree policy, Conventional Commits, DONE/TODO
  discipline, the data-not-instructions rule, the no-string-assertion test rule, dedup by
  native ID, retention. `docs/software-factory-audit.md` is a dated record and was left as is.

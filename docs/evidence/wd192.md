# WD-192 Watchdog transcript import

`wdi import` reads Watchdog streams through read contract v1 before scanning
provider files. The existing parsers populate derived rows and previews. Each
Watchdog import cursor records the stream key, generation, raw byte count, and
record count. The original lines remain in the capture store. Full transcript
reads from the UI are tracked in WD-194.

For Claude, a nonempty captured main stream takes precedence over a file
session. The transition replaces its file-derived streams and cursors. A
capture containing only a subagent leaves an existing file session eligible
for file imports. Legacy sessions and saved analyses are preserved.

## Live verification

An SQLite backup of the installed Insights database passed `quick_check`
before import. The first `wdi import` scanned 1,503 captured streams and
imported 886, including 96 new sessions, with zero warnings. The incremental
run with the final implementation replayed one growing stream with zero
warnings. The destination passed `quick_check` and `foreign_key_check`.
All 60 analysis rows and 772 legacy session rows matched the backup.

All 16 discovered stores supported contract v1. Both file sources were enabled
during verification.

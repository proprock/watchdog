# WD-218 verification

`wdi analyze` reads `features.llm_analysis.backend` and accepts `claude` and
`codex`. The legacy value `claude-cli` selects Claude. Codex uses the existing
ephemeral CLI invocation and returns text to the session analyzer. The web
advisers retain their structured response contract.

The offline CLI regression loaded a YAML configuration, verified the selected
executable, model and invocation flags, and checked that the analyzer stored
the returned score and summary. Configuration tests cover an invalid backend
and the Codex default model. The full Insights suite passed 311 tests with one
Starlette deprecation warning. Ruff lint and formatting, ty, both package builds
and diff hygiene passed. Provider calls were simulated.

# WD-194 full transcript reads

The analyzer context and tool detail route read captured streams through
`readapi.lines` and local transcripts through the same stream reader. The
configured Watchdog data directories apply to both the web server and the
analyzer estimate and execution paths. Missing full text is marked unavailable.

The Claude persisted-output format was confirmed in 50 local tool results.
The detail route resolves the referenced file in the capture for that session
and reads its bytes through `readapi.side_file_bytes`. The reference format
and captured path are documented in [Insights gotchas](../../insights/GOTCHAS.md#claude-tool-results-stored-beside-the-transcript).

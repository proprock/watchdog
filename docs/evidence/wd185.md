## Migration commands and rollback

The native hooks launch Python from the absolute `--python` path in their installed commands. The replacement environment therefore needs to be built at the original path. Use the verified `agent-watchdog` wheel and the existing `--python`, `--config`, `--data`, and `--runtime` values from the installed hooks. Resolve the environment path and confirm the backup path is unused before making changes. Preserve the old environment for rollback.

Run from the repository root in PowerShell. Set `$livePython`, `$liveConfig`, `$liveData`, and `$liveRuntime` to the installed values. Check each command's exit status before continuing.

```powershell
$liveArgs = @('--config', $liveConfig, '--data', $liveData, '--runtime', $liveRuntime)
$liveVenv = (Resolve-Path -LiteralPath (Split-Path (Split-Path $livePython))).Path
$backupName = (Split-Path $liveVenv -Leaf) + '.wd185-py312'
$backupVenv = Join-Path (Split-Path $liveVenv) $backupName
if (Test-Path -LiteralPath $backupVenv) { throw 'The backup path is already in use.' }
$requirements = Join-Path $env:TEMP ('wd185-runtime-' + [guid]::NewGuid() + '.txt')
$wheel = (Resolve-Path -LiteralPath 'dist/agent_watchdog-0.1.5-py3-none-any.whl').Path

uv export --locked --package agent-watchdog --no-dev --no-emit-workspace --format requirements.txt --output-file $requirements
& $livePython -m agent_watchdog @liveArgs daemon status
& $livePython -m agent_watchdog @liveArgs daemon stop
Rename-Item -LiteralPath $liveVenv -NewName $backupName -ErrorAction Stop
uv venv --python 3.14 $liveVenv
uv pip sync --python $livePython --require-hashes $requirements
uv pip install --python $livePython --no-deps $wheel
uv pip check --python $livePython
& $livePython -c 'import compression.zstd, sys; print(sys.version)'
& $livePython -m agent_watchdog @liveArgs daemon start
& $livePython -m agent_watchdog @liveArgs daemon status
& $livePython -m agent_watchdog @liveArgs doctor
```

Record the interpreter version, daemon status, and redacted `doctor` result. Confirm that fresh hook events reach SQLite. If a step fails after the environment rename, stop the replacement daemon if it started, rename the replacement environment out of the way, restore the old environment at its original path, and start it with the same arguments if it was running before the migration.

The new configuration and database are under `~/.wdi/`. The configuration retained the machine ID and import settings from the old application and points at `~/.wdi/wdi.sqlite`.

## Automated verification

The focused tests covered schema rejection, CLI/web/MCP database opening, rebuild backup and retention, retry-safe legacy import, conflicting paid records, provider import races, and legacy session snapshots. A synthetic WAL probe imported a committed WAL-only session while preserving the original database and sidecar bytes. A concurrent initialization probe passed 80 opens across 10 new databases.

`uv run --directory insights pytest` passed all 277 tests. The suite emitted a Starlette TestClient deprecation warning. Ruff lint and format, type checking, and the build of both workspace packages passed.

The first root Watchdog suite ran concurrently with the local database work. It reported 2,105 passed, 85 failed and one skipped. The failures included subprocess and daemon timeouts in Watchdog CLI, daemon, native adapter and storage tests. Four representative failures passed in a sequential rerun.

After the live import and other checks finished, the root suite reported 2,188 passed, two failed and one skipped. `test_daemon_captures_a_hook_named_transcript` observed capture schema revision 0 while expecting 3. `test_native_gives_up_on_a_silent_daemon_after_the_published_budget` measured 1.23 seconds against a one-second test limit. Both passed together in a sequential rerun. The remaining parallel-suite investigation is tracked in WD-217.

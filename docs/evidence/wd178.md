# WD-178: harness version drift

The adapter preserves its Codex control profile as delivery metadata. The daemon
compares that profile with the first session metadata record in the matching
captured stream using bounded reads. A mismatch creates a finding; missing,
invalid, unreadable or oversized metadata remains unknown. Capture progress
reschedules findings, and a restart retries previously unknown comparisons.
Status and doctor report drift observed in retained sessions. No control decision
or provider call is added.

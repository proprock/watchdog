# WD-196: Environment and repository outcome in Insights

Verified on 2026-11-13.

## Delivered behavior

- `readapi.session_env` and `checkout_states` expose paged snapshot metadata;
  `blob_bytes` reads captured content on demand. Older capture schemas yield no
  unavailable snapshot tables, and schema 2 initial statistics remain null.
- Insights schema revision 4 contains derived environment and checkout tables.
  Each import refreshes metadata atomically per machine/source project, including
  late snapshots and source purges. Blobs are never copied into Insights.
- Session pages show directory, commit, branch, model, instruction/settings file
  digests and change markers, Watchdog rules, observed checkout statistics and
  HEAD movement. The previous actual session of the same project supplies the
  comparison; missing evidence remains unavailable.
- Branch, repository-change and instruction-change filters run before the list
  limit, support full pages and HTMX, and preserve URL state. Advice cache keys
  distinguish the new filters. Watchdog session source keys constrain snapshot
  selection when another store contains the same session ID on the same machine.
- Captured initial and outcome patches render on demand with HTML escaping.
  Initial patches remain reachable after later environment snapshots. Checkout
  statistics can include pre-existing edits; the captured outcome patch is
  against the observed HEAD and does not contain committed changes between HEADs.

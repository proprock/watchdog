## Implementation and regression verification

without importing collector inspection or the daemon. They preserve aliases,
UUID selection, cwd/linked-worktree resolution, multiple configured source roots,
JSON errors, snapshot identities, unavailable/schema states, and export boundaries.
The legacy commands, inspection implementations, pricing/facts modules, config
field, and benchmark script are removed. Shared session labels live in readapi.
Retained collector behavior stays covered in the root suite; export, usage,
overview, and cost contracts moved to Insights tests.

One Decimal engine prices dated complete tables, matches the longest model
prefix, prefers cache_write_5m including zero, and reports explicit unpriced
reasons. User tariffs replace defaults entirely. Existing parsed session input
is already net of cache reads; original provider counters retain Codex/Claude
conventions. Session costs resolve dates before grouping; a partly unpriced model
remains unavailable. Partial tariffs can price known counters without inventing
free rates or crashing prompt estimation.

frozen old resolver for all seven default keys, respectively:

These are compatibility rates, not a claim about current provider prices.

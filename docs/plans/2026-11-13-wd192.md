1. Add synthetic store tests in `insights/tests/test_ingest_watchdog.py` for parity, growth, generation replacement, stream mapping, discovery, and source precedence. Run the focused suite and commit the expected failures with the `TDD: red` trailer.
2. Adapt `insights/src/wdi/ingest/runner.py` to share parse and persistence logic between a file source and a Watchdog source. Keep file offsets and the parser interface. 3. Make stream replacement, provenance, and cursor updates atomic. Recheck origin under the write lock. Preserve legacy rows and paid analyses during source handoff. Prefer Watchdog over file sources and keep main streams ahead of Claude subagent streams.
4. Wire discovery and settings into `wdi import` and add `wdi doctor` with store and per-provider coverage. Document `watchdog.data_dirs` and the file-source retirement threshold in `insights/README.md`.
5. Run the focused and full Insights suites, the root suite, Ruff, ty, and the workspace build. Verify the live import and capture aggregate doctor output in `docs/evidence/wd192.md`. Close WD-192 after acceptance and commit the verified solution with the `TDD: green` trailer.

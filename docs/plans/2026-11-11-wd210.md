# WD-210 Implementation Plan

**Goal:** Bound idle project work without delaying new spool ingestion or hiding storage health.

**Architecture:** Schedule each project's visits with capped idle backoff and wake the affected project after a committed spool write. Load transcript reader state only for sources that need it. Bound aggregate storage health scans and identify unvisited projects as unavailable.

**Verification:** Add deterministic fake-clock scheduling, wakeup, transcript growth and 40-project health tests; establish failing red tests before implementation. Run focused tests, the full suite, static checks and package build. Measure live idle tick cost before and after the update, then observe ingestion for one hour and record evidence before closing WD-210.

**Constraints:** Keep all state in the existing daemon loop; preserve error and retention semantics, introduce no threads, processes or queues, and do not change live provider hooks.

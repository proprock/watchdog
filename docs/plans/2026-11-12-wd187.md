# Raw transcript capture implementation plan

**Goal**

Capture hook-named raw transcript bytes in a separate per-project store and verify their preservation through rotation, compression, and restart.

**Architecture**

Use a versioned SQLite store for stream offsets, record tails, sealed zstd blocks, and Claude side files. Run a bounded capture pass from the daemon after enrichment. Keep the events schema at version 9. Read only hook-named sources and the associated Claude session directories. A provider-directory backfill and the public read contract have their own tickets.

1. Exercise schema creation and version rejection, durable writes, sealing, and byte-exact readback in `tests/test_capture_store.py`. Implement `src/agent_watchdog/capture_store.py` after the red check.
2. Exercise source identity, incremental reads, storage limits, rotations, compressed replacements, side files, and the pass deadline in `tests/test_capture.py`. Implement the pass in `src/agent_watchdog/capture.py` after the red check.
3. Connect the pass in `daemon.py`, add capture data to `inspection.doctor`, and extend `Store.purge_provider_session`. Exercise those entry points with synthetic data before running the root suite.
4. Measure zstd with `scripts/measure_zstd.py`, record the results in `docs/evidence/wd187.md`, and document the schema and operating contract in `docs/storage.md` and `docs/architecture.md`.
5. Run focused pytest modules, the root suite, Ruff, ty, and both package builds. Install the verified wheel using the local deployment procedure. Confirm `doctor` and compare captured records to their original bytes after one real session per provider. Close the ticket only after all acceptance checks pass.
